# 시프기_포인터_무한소수계산기

자릿수 제한 없이 **사칙연산(+, -, *, /)** 을 오차 없이 계산하는 C 언어 계산기입니다.
`int`나 `double`을 쓰지 않고 수를 직접 자릿수 배열·연결리스트로 다루기 때문에, 수백~수천 자리 정수와 긴 소수도 정확하게 계산합니다.
나눗셈은 분수로 계산하고 끝나지 않는 소수는 순환마디를 괄호로 표시합니다.

```
Input  : 324134341341413.319434913*2123291392139123.39123921+1321321.43234342
Result : 688231656866907303054803484014.95912391200853873

Input  : (-22)/7
Result : -3.(142857)
```

- 언어: C (C 표준 라이브러리만 사용, 외부 라이브러리 없음)
- 원본 프로젝트: [JJongmen/InfCal](https://github.com/JJongmen/InfCal)

---

## 주요 기능

| 기능 | 예시 입력 | 결과 |
|---|---|---|
| 덧셈 / 뺄셈 | `10+25` | `35` |
| 곱셈 | `394324984289489*14843804302429` | `5853282898351564649841868781` |
| 소수 곱셈 | `(-1.5)*5.2` | `-7.8` |
| 나눗셈 (나누어떨어짐) | `1/1024` | `0.0009765625` |
| 나눗셈 (순환소수) | `1/6` | `0.1(6)` |
| 분수로 정확 계산 | `1/3*3` | `1` |
| 연산자 우선순위 | `10-2*3+1` | `5` |
| 괄호, 음수 | `(1.5+2)/(0.25-1)*4` | `-18.(6)` |
| 괄호 앞뒤 곱셈 생략 | `3(4)`, `(1+2)(3+4)5+2(-1.5)` | `12`, `102` |
| 0으로 나누기 | `5/0` | `divide by zero` |
| 잘못된 식 | `1++5` | `wrong expression` |

### 순환소수 표기
- 반복되는 부분(순환마디)을 괄호로 감쌉니다: `1/3 = 0.(3)`, `1/7 = 0.(142857)`, `31449/9999 = 3.(1452)`
- 순환마디가 10000자리를 넘으면 앞부분 10000자리만 출력하고 끝에 `...`을 붙입니다. 내부 값은 분수라서 정확하고, 출력만 줄인 것입니다.

## 빌드

gcc가 필요합니다.

```
gcc -O2 calc.c linklist.c check.c change.c postfix.c seccalc.c rational.c stack.c stackL.c -o infcal.exe
```

> `3_fund_cal.c`는 덧셈/뺄셈 단독 테스트용 파일(자체 `main` 포함)이라 빌드에 넣지 않습니다.

## 실행

수식을 한 줄 적은 텍스트 파일을 인자로 넘깁니다.

```
echo 1/3+1/6> input.txt
infcal.exe input.txt
```

```
====== Welcome to infinite calculator! ======
Enter the expression in infix notation.
Input : 1/3+1/6
Result : 0.5
```

## 입력 규칙 (예외 처리)

다음과 같은 입력은 `wrong expression`으로 처리합니다.

| 규칙 | 에러 예시 | 허용 예시 |
|---|---|---|
| 허용 문자는 `0-9 . ( ) + - * /`와 공백뿐 | `4ㅎ8x1`, `502_41` | |
| 맨 앞이 `.`, `*`, `/`, 공백 | `.5+1`, `*3` | `-5+1`, `+5` |
| 연산자가 연속으로 나옴 | `1++5`, `2///7`, `6//2` | `1+2` |
| 연산자로 끝남 | `5+`, `3*`, `6/`, `5+ ` | |
| 앞자리 0 | `041*45`, `029+482` | `0`, `0.5`, `100`, `10.05` |
| 한 숫자에 소수점이 2개 이상 | `2..59*5.004.5` | `2.59*5.0045` |
| 소수점 뒤에 숫자가 없음 | `5.`, `5.+1` | `5.0` |
| 괄호 짝이 안 맞거나 순서가 틀림 | `(1+2`, `37))28(+5` | `(1+2)` |
| 빈 괄호 | `()`, `(1+2)()` | |
| `(` 바로 뒤에 `*`, `/` | `(*3)` | `(-3)`, `(+3)` |
| 숫자 사이에 공백 | `1 2` | |

- 맨 앞이나 `(` 바로 뒤의 `+`, `-`는 부호로 인식합니다: `-5+1`, `(-3)*2`
- 식 끝의 공백은 무시합니다: `1+2 ` → `3`
- 0으로 나누면 `divide by zero`를 출력합니다: `5/0`, `5/(3-3)`

## 동작 흐름

```
파일 입력 → 연결리스트 저장 → 유효성 검사 → 식 다듬기 → 후위표기식 변환 → 분수 계산 → 소수로 출력
  calc.c       linklist.c        check.c      change.c       postfix.c        rational.c
```

1. **입력** (`calc.c`): 파일에서 수식을 한 글자씩 읽어 문자 연결리스트에 저장합니다.
2. **검사** (`check.c`): 위 입력 규칙을 검사합니다.
3. **다듬기** (`change.c`)
   - 부호 처리: `-1` → `0-1`, `(-1` → `(0-1`
   - 곱셈 생략 보완: `3(4)` → `3*(4)`, `(2)(3)` → `(2)*(3)`, `(2)3` → `(2)*3`
4. **후위표기 변환** (`postfix.c`): 연산자 스택으로 우선순위(`* /` > `+ -`)와 왼쪽 결합을 처리합니다.
5. **계산** (`rational.c`): 후위식을 스택으로 계산합니다. 모든 값은 기약분수(부호, 분자, 분모)입니다.
6. **출력** (`rational.c`): 분수를 소수로 바꾸고 순환마디에 괄호를 칩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `calc.c` | `main`: 입력, 단계별 호출, 결과/에러 출력 |
| `calc.h` | 자료구조와 함수 선언 |
| `linklist.c` | 문자 연결리스트 (삽입, 삭제, 검색, 비교) |
| `stack.c` | 연산자 스택 (후위표기 변환용) |
| `stackL.c` | 연결리스트를 담는 스택 (예전 계산기용) |
| `check.c` | 입력 유효성 검사 |
| `change.c` | 부호 처리, 생략된 곱셈 기호 삽입 |
| `postfix.c` | 중위 → 후위 표기 변환 |
| `rational.c` | 큰 자연수와 분수 연산, 소수 변환 (현재 계산 엔진) |
| `seccalc.c` | 초기 버전 연결리스트 기반 `add` / `minus` / `multiply` (현재는 호출되지 않음, 참고용) |
| `3_fund_cal.c` | 초기 덧셈/뺄셈 단독 테스트 |
| `tests/` | 테스트 입력 파일 |

## 내부 구현

### 분수(유리수) 연산
- 입력 숫자 `123.45`는 `12345/100`으로 바꾸고 바로 약분합니다.
- 모든 연산 결과는 항상 기약분수로 유지합니다. 그래서 `1/3*3 = 1`, `1/3+1/6 = 0.5`처럼 중간에 나눗셈이 있어도 오차가 없습니다.
- 덧셈·뺄셈: `g = gcd(분모1, 분모2)`로 공통분모를 최소로 잡고, 결과 약분은 `gcd(분자, g)`만 계산합니다.
- 곱셈·나눗셈: 계산 전에 교차 약분해서 결과가 바로 기약분수가 됩니다.

### 큰 자연수
- 10000진법 배열(칸 하나에 10진 4자리)에 저장합니다.
- 곱셈은 세로셈 방식입니다. 칸끼리의 곱을 `long long`에 모은 뒤 올림을 한 번에 처리합니다.
- 긴 나눗셈은 몫의 한 칸을 상위 자리로 어림한 뒤 보정합니다. 어림이 틀려도 결과는 항상 정확합니다.
- 버퍼를 재사용하고 용량을 2배씩 늘려서, 자리마다 메모리를 새로 할당하지 않습니다.
- 최대공약수는 유클리드 호제법을 씁니다. 나눗셈이 몫의 길이에 비례하는 비용으로 끝나서 전체 O(n²)입니다.

### 순환마디 찾기
- 분모를 `2^a × 5^b × m`으로 나누면, 순환하지 않는 앞부분은 `max(a, b)`자리입니다.
- 그 뒤로는 나머지가 처음 값으로 돌아올 때까지 한 자리씩 나누고, 그 구간을 괄호로 감쌉니다.

### 성능 (최적화 전후, `-O2` 빌드)

| 케이스 | 최적화 전 | 최적화 후 |
|---|---|---|
| 5000자리 × 5000자리 곱셈 | 0.385초 | 0.074초 |
| 긴 소수끼리 나눗셈 (10000자리 출력) | 3.247초 | 0.140초 |
| 1/1 + 1/2 + … + 1/400 | 1.299초 | 0.050초 |
| 30자리 소수 60개 곱 | 24.752초 | 0.086초 |

## 테스트

`tests/` 폴더에 입력 파일이 있습니다. 파일 이름 앞부분으로 종류를 구분합니다.

| 접두사 | 내용 |
|---|---|
| `ok_` | 정상 입력 (긴 정수, 긴 소수, 우선순위, 곱셈 생략 등) |
| `div_` | 나눗셈 (유한소수, 순환소수, 음수, 0으로 나누기 등) |
| `err_` | 잘못된 입력 (연속 연산자, 잘못된 문자, 앞자리 0 등) |
| `edge_` | 경계 케이스 (연산자로 끝남, 빈 괄호, 끝 공백 등) |

Windows cmd에서 전체 실행:

```
for %f in (tests\*.txt) do @(echo === %~nf & infcal.exe %f | findstr /b "Input Result wrong divide")
```

긴 정수와 소수 결과는 파이썬 `decimal` / `fractions` 계산값과 대조해 확인했습니다.
